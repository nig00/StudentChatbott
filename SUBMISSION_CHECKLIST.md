### Screenshot advice

- Capture the real application window with the relevant name, setting, or test conversation visible.
- Keep the entire user query and a meaningful section of the assistant's response in frame.
- **Hide or redact the value of your API key**, access tokens, passwords, and account/private details. Header *names* can remain visible.
- Do not submit local unit-test output as a substitute for Watson chatbot response screenshots.
- Arrange the files in the order shown above for reviewers.
- These evidence files cannot be prepared truthfully until your GitHub repository and Watson Assistant skill are actually configured.
